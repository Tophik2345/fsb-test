# ФСБ УП-9 — защищённый игровой редактор документов

Отдельный серверный раздел. GitHub хранит код и исходные шаблоны, но не пароли и не рабочие данные. GitHub Pages для этой версии не подходит: он не выполняет проверку пароля на сервере.

## Развёртывание

Нужен Node.js 20+ и HTTPS-домен. На сервере выполните `npm run setup` и задайте **два разных пароля от 16 символов**. Команда выведет хеши и ключ сессий; сохраните их в защищённых переменных окружения сервера, а не в репозитории. Укажите также `PUBLIC_ORIGIN=https://ваш-домен` и `DATA_FILE=/закрытый/путь/templates.json` (каталог должен быть доступен на запись только процессу приложения). Затем `npm start`. Проксируйте HTTPS на `PORT` приложения. Не передавайте `.env` в GitHub.

Для локальной проверки разрешён `PUBLIC_ORIGIN=http://localhost:3000` и `ALLOW_INSECURE_LOCAL=1`. В рабочем окружении этот параметр не задавайте.

Сессия живёт восемь часов в cookie HttpOnly, Secure и SameSite=Strict. Шесть неудачных попыток с одного IP блокируют вход на 15 минут. Пользователь может просматривать, редактировать и скачивать документы; администратор дополнительно сохраняет текущий документ как новый шаблон и удаляет шаблоны. Изменения шаблонов хранятся в `DATA_FILE`. Для нескольких экземпляров сервера потребуется общая база данных и общий ограничитель попыток.

Это ролевая игровая страница, не официальный ресурс государственного органа.
